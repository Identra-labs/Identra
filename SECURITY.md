# Security policy

Identra is pre-alpha, testnet-only and has not been audited. Do not use it with
real funds or real personal data.

## Reporting a vulnerability
Please do not open a public issue. Contact the maintainer privately at
<SECURITY CONTACT EMAIL> with a description, reproduction steps and the affected
version. You can expect an acknowledgement within a few days.

## Scope
Contracts, the SDK, the CLI and the documentation in this repository.
